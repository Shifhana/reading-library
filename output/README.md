# Reading Garden development archive

These screenshots, generated images, geometry snapshots and implementation reports document earlier development passes. Archived to GitHub at the owner's request after the final release.

They are historical review artifacts, not the current product specification. Reports may describe superseded designs, interactions or test totals. Current application code is in `src/`; final release checks are recorded in `docs/FINAL-QA.md`.

Personal browser-saved notes are intentionally excluded. Installed dependencies (`node_modules/`) and generated builds (`dist/`) are also excluded and can be recreated from the committed source and lockfile.

Final site: https://myreadinggarden.netlify.app
